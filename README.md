# Wars — a mobile-friendly Warcraft-like RTS

A Warcraft 1/2-inspired real-time strategy game built for touch: HTML5 Canvas + TypeScript, flat geometric art, command-button controls.

## Run

```bash
npm install
npm run dev        # game at http://localhost:5173
npm test           # unit tests
npm run build      # typecheck + production build
```

Persistence server (MongoDB Atlas):

```bash
cp .env.example .env   # fill ATLAS_URI
npm run server   # persistence API at http://localhost:3001 (requires .env + Node >= 20.6)
```

## Controls (landscape)

- Tap unit/building to select; drag empty ground to pan; pinch to zoom; minimap tap to jump
- Command bar: Attack / Move / Stop / Hold; workers: Build / Gather
- "All" button selects all combat units

## Audio

- SFX generated by `tools/gen-sfx.mjs` (jsfxr) into `public/sfx/` — edit presets, re-run
- Music: "Welcome to The Games" from Mixkit (free stock music license, no attribution required), `public/audio/music.mp3`

## Layout

```
src/core     game loop, camera, gesture input
src/world    entities, map, systems (movement/combat/economy/building/ai)
src/render   canvas renderer (flat geometric)
src/ui       hud, minimap, screens
src/state    session controller, tick orchestration
src/content  units, buildings, missions data
src/net      progress API client
server/      express + mongodb progress API
tools/       jsfxr sfx generator
```
